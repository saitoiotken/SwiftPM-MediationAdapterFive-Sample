# FluctSDKMediationAdapterFive

## Introduction

FIVE custom event for FluctSDK mediation, distributed via [Swift Package Manager](https://swift.org/package-manager/).

## Requirements

- iOS 15.0 or later
- Xcode 15.3 or later (FiveAd's package requires swift-tools-version 5.10)

## Installation

Add this package to your project and link the `FluctSDKMediationAdapterFive` product.
FluctSDK and FIVE SDK are resolved as dependencies of this package.

Add `-ObjC` to **Other Linker Flags** of your app target.
